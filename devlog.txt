Sessions 1 & 2 summary: audio_server.py was built to run an AudioAnalyzer and broadcast beat, volume, band energy, and dominant frequency as JSON frames at ~60 fps over a WebSocket on localhost:8765. visualizer.html was then created as the frontend scaffold — it loads Three.js r128 from CDN, connects to the WebSocket with auto-reconnect, logs all incoming audio data to the browser console, renders a black fullscreen canvas, and shows a color-coded Connected/Disconnected status chip in the top-left corner.

Session 3 changes summary: A centered drop-zone overlay (dashed circle + monospace label) now appears over the black canvas when no photo is loaded, brightening on dragenter to give clear visual feedback. Dropping any image file reads it via FileReader, wraps it in a THREE.Texture, and places it on a unit PlaneGeometry whose scale is computed from the camera's FOV so the image fills exactly 60% of the visible world height with aspect ratio preserved — and re-fits automatically on window resize. A ShaderMaterial applies a GLSL radial vignette: dist = length(uv - 0.5) * 2.0 fed through smoothstep(0.35, 1.05) gives full brightness at the center and pure black at the corners. Dropping a second photo cleanly disposes the previous texture, material, and geometry before replacing the mesh.

Session 4 summary: `visualizer.html` was rebuilt with a full multi-photo workflow — dropping files or a folder runs `collectFiles()` which recursively reads directory entries via `webkitGetAsEntry` and sorts all images alphabetically into `queue[]`. **Setup mode** walks a `setupPending[]` array showing each photo one at a time with a draggable `#v-handle` circle (positioned in screen pixels over the photo using `photoPixelBounds()`) and Lock / Skip buttons; Skip moves the current photo to end of the setup queue, Lock saves `{ cx, cy, scale }` per filename to `photoSettings` and POSTs the whole object to `http://localhost:8080/save_settings`. **Performance mode** begins when all photos are locked — a `setTimeout` chain advances `currentPhotoIdx` every 45 seconds; the bottom-right counter (`N of M`) becomes clickable to open a popover listing all filenames, and clicking any filename pauses the cycle and re-enters single-photo adjustment mode, returning to performance on re-lock. The vignette shader was upgraded to elliptical using three uniforms (`uVignetteCenter`, `uVignetteAspect`, `uVignetteScale`) — dividing the x offset by `imgW/imgH` produces a wide oval for landscape photos and a tall oval for portrait. `audio_server.py` gained a `ThreadingHTTPServer` on port 8080 in a daemon thread, serving `GET /photo_settings.json` from disk and `POST /save_settings` that validates and writes the settings file with CORS headers; the WebSocket broadcast on port 8765 is unchanged.
